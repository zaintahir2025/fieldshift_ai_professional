## Draft disclosure for this project

FIELDSHIFT AI uses conventional software components and data-processing methods to present Earth-observation information for agricultural decision support. The current prototype includes a React interface, a FastAPI service, NASA POWER daily weather retrieval, NASA GIBS imagery overlays, transparent rule-based indicators, and optional Random Forest training/inference code.

Generative AI assistance was used during project development for code review, debugging suggestions, documentation drafting, and preparation of explanatory text. The team remains responsible for the project concept, source verification, implementation decisions, testing, and all submitted claims. Any AI-generated visual or audio assets used in the final submission must be identified as AI-generated in the manner required by the challenge. No generated asset should include NASA logos, insignia, flags, or mission identifiers.
